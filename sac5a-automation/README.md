# SAC-5A（定刻起床装置 個人簡易型）毎晩の予約を自動化する

JR の乗務員宿泊所で使われている定刻起床装置の個人簡易型 SAC-5A（新光電業）は、
毎晩「起床予約」をしないと動きません。この「毎晩の予約」を自動化し、
スマホから操作できるようにするためのガイドと自作ファームウェア一式です。

## 結論（TL;DR）

- SAC-5A に「毎日繰り返し」機能は**ない**。毎晩の予約操作が必要（これは仕様）
- ただし取扱説明書 P.9 に重要な記載がある:
  **「起床時刻に変更がない場合は、［アラーム］ボタンを押すだけで起床設定ができます」**
  → 毎晩必要な操作は、実は**ボタン 1 回だけ**
- なので解決策は「**その 1 回を毎晩、機械に押させる**」こと。方法は 2 つ:
  1. **SwitchBot ボット**を貼る（工作不要・約3,000円・アプリでスケジュール）← まずはこれ
  2. **ESP32 + サーボで自作**（約2,000円・スマホのブラウザから操作）→ [`sac5a_arm_bot/`](sac5a_arm_bot/)
- 本体の**分解・配線改造はしない**。取説で禁止されており、内部は AC100V（感電・火災リスク）、保証も消える

## 取扱説明書からわかった重要仕様

公式取説（[PDF](https://sort-inc.net/p2-product/a1-kisyou/images/pdf/2_k-1-1-2022.pdf)）を読んで確認した、自動化に効く仕様:

| 仕様 | 内容 |
|---|---|
| 予約のワンタッチ化 | 起床時刻に変更がなければ［アラーム］ボタン 1 回で予約完了（Alarm ON 表示・LED 点灯） |
| 予約の解除 | 予約中にもう一度［アラーム］を押すと**解除** → 二重押しに注意 |
| 設定の保持 | 現在時刻・起床時刻・各種設定は停電でも電池交換でも保持される |
| 繰り返し機能 | なし。起床動作（またはその夜の予約忘れ）のあとは、再度予約するまで作動しない |
| 起床動作 | 設定時刻に送風機が 3 分動作（15秒→以降9秒間隔でON/OFF）、その後ブザー3分。停止は［停止A］＋［停止B］同時押し |
| 予約の前提 | 送風機のプラグが制御タイマーに刺さっていないとエラーで予約不可 |
| 電源系 | 制御タイマー（SUK-49）AC100V・送風機（KB-100）AC100V 181W を制御タイマーのコンセントで駆動 |
| 禁止事項 | 分解・改造の禁止が明記。制御タイマーのコンセントに送風機以外を繋ぐのも禁止 |

**迷ったら方式1。** 電子工作に興味があるなら方式2（このリポジトリにコード一式あり）。両方やって比べるのもあり。

## 方式1: SwitchBot ボット（おすすめ・工作不要）

SwitchBot ボットは「物理ボタンを指で押す」ことに特化した小さいロボットで、まさにこの用途のための製品です。

1. SwitchBot ボットを購入（Amazon 等で約3,000円）
2. スマホに SwitchBot アプリを入れて Bluetooth でペアリング
3. SAC-5A 制御タイマーの**［アラーム］ボタンの真上**に付属の両面テープで貼り付け
   - ディスプレイと［停止A］［停止B］ボタンを塞がない位置に
4. アプリの手動操作で試し押し → 本体に「Alarm ON」が出て LED が点灯すればOK
   - もう一度押すと解除になるので、テスト後の LED 状態に注意
5. アプリの「スケジュール」で **毎晩の押し時刻**（例: 21:30、曜日別も可）を設定
   - スケジュールはボット本体に保存されるので、スマホが家になくても毎晩動きます
6. 数日はアラーム LED が毎晩点くことを目視確認

外出先から押したい・Alexa で「アラームセットして」と言いたい場合は SwitchBot ハブミニを追加。
公式 API も公開されているので、後々「Google カレンダーの予定に合わせて押す/押さない」のような連携も作れます。

## 方式2: ESP32 + サーボで自作

約2,000円で作る、Wi-Fi 接続のボタン押しロボットです。ファームウェアと組み立て手順は
[`sac5a_arm_bot/`](sac5a_arm_bot/) にあります。

できること:

- 曜日ごとに「予約ボタンを押す時刻」を設定（平日だけ、週末は遅め、など）
- スマホのブラウザから `http://sac5a.local/` で操作（アプリ不要）
- 「次の 1 回だけスキップ」（明日は休み、という夜用）
- 今すぐ押す（テスト・手動予約）
- NTP で時刻自動同期（時刻がズレて変な時間に押す事故を防止）
- 押し履歴のログ表示

## 運用ルール（どちらの方式でも大事）

1. **予約は機械に一本化する。** 手でもアラームボタンを押すと、機械が押したときに解除されてしまう（最悪の寝坊パターン）
2. 導入後 1 週間は、寝る前にアラーム LED が点灯しているか目視確認する
3. 起きる時刻を変えたい日は、本体で起床時刻を変更して［決定］を押す（この操作自体で予約が入る）。
   その夜の自動押しはスキップしておく
4. 起きなくていい日はスケジュール OFF またはスキップ
5. 送風機のプラグが抜けていると予約自体がエラーになるので、掃除のあとなどは接続を確認
6. **起床時の停止ボタン（停止A+停止B）は自動化しない。** それを自動化したらただの寝坊装置になる

## やってはいけないこと

- 制御タイマーの分解・ボタン配線への割り込み（取説で禁止・内部 AC100V・保証喪失）
- スマートプラグで送風機を直接 ON/OFF する方式（制御タイマーが 15秒/9秒間隔の膨張制御と
  安全監視をしているため。制御タイマーのコンセント以外に送風機を繋ぐのも取説で禁止）
- スマートプラグで制御タイマーの電源を切る運用（予約は入らないし、停電扱いで 10 分後に停電警報ブザーが鳴る）

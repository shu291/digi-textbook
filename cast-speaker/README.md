# スピーカーリモコン (Google Home / Nest 連携)

スマホのブラウザから音声ファイルを選ぶ → Google Home / Nest スピーカーで再生。
音量・一時停止・停止・ループ再生もスマホから操作できます。

```
スマホ(ブラウザ) ──HTTP──▶ このサーバー(PC/ラズパイ) ──Cast──▶ Google Home
                              └─ 音声ファイルを配信 ◀──────────────┘(スピーカーが取りに来る)
```

## 使い方
同じWi-Fiにつながった PC / Raspberry Pi など(常時起動できるもの)で:

```bash
cd cast-speaker
npm install
npm start
```

表示されたURL(例 `http://192.168.1.10:8080`)をスマホで開く →
スピーカーを選ぶ → ファイルをアップロード → ▶ をタップ。
ホーム画面に追加するとアプリ代わりに使えます。

| 環境変数 | 意味 |
|---|---|
| `PORT` | ポート番号(既定 8080) |
| `TOKEN` | 設定すると操作に合言葉が必要(家族以外に使われたくない時) |
| `PUBLIC_URL` | スピーカーから見たこのサーバーのURL(通常は不要) |

対応形式: mp3 / m4a / aac / wav / ogg / flac / opus

## 犬を落ち着かせる使い方
1. 飼い主さんの声(「だいじょうぶだよ〜」など)や犬用のリラックス音楽をアップロード
2. ファイル横の ☆ をタップして「落ち着く音」に設定
3. 騒いだら「🐶 落ち着かせる」をタップ → ループ再生、「自動で止める」(既定30分)で自動停止

**外出先から使いたい場合**: このサーバーのPCとスマホに無料の VPN アプリ [Tailscale](https://tailscale.com) を入れると、外出先のスマホからも同じURL(Tailscaleのアドレス)で操作できます。インターネットに直接公開するのはやめてください。

## 注意
- スマホ・サーバー・スピーカーは**同じWi-Fi(同じネットワーク)**に置くこと。ゲスト用Wi-Fiだと探索できないことがあります。
- 外出先からは使えません(家のLAN内専用。インターネットには公開しないでください)。
- Docker で動かす場合は `--network host` が必要です(スピーカー探索にmDNSを使うため)。
- 実機のスピーカーでは未検証です(サーバーAPIのみテスト済み)。動かない時は `npm start` のログを教えてください。

## もっと手軽な代替: Bluetooth
Google Home / Nest Audio 等は Bluetooth スピーカーとしても使えます。
「OK Google、Bluetoothペア設定して」→ スマホのBluetooth設定でスピーカーを選ぶ → スマホの音が全部スピーカーから出ます。
ファイルを選ぶだけで済むならこれが一番簡単。このシステムは「PCを経由してスマホ無しでも流し続けたい」「ボタン一つで選曲・ループしたい」用途向けです。

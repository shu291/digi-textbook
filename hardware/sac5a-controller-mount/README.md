# SAC-5A 制御タイマー用 ベッドフレーム・ホルダー

定刻起床装置 個人簡易型 **SAC-5A型**（新光電業株式会社）の
**制御タイマー〈型式 SUK-49〉**＝「ボタンがたくさん付いている方」を、
**43 × 43 mm の角パイプ製ベッドフレーム**に取り付けるための 3D プリント部品です。

- 角パイプに **上からかぶせる**サドル（∩形）
- その**側面（ベッドの外側）にぶら下がるポケット**
- 制御タイマーは**上から落とし込んで**差し込む

## 1. 寸法の根拠

### 制御タイマー（SUK-49）

新光電業(株) SAC-5A型 取扱説明書「主な製品仕様」より：

| 項目 | 値 |
|---|---|
| 外形寸法 | **高さ 120 × 幅 120 × 奥行 60 (mm)** |
| 重量 | **500 (g)** |
| 定格電圧 / 電力 | AC100±10% (V) / 10 (W) |
| 使用電池 | 単3形アルカリ乾電池 2本 |

同説明書の外観図から読み取った、設計上で避けなければならない要素：

| 面 | 要素 | 本設計での扱い |
|---|---|---|
| 正面 | 上部に **停止ボタン A / B**、ディスプレイ | サドルより上に出るので干渉なし |
| 正面 | 下半分に **操作ボタン 11個**（メニュー / アラーム / 起床設定 / 戻る / 決定 / すすむ・もどる / 切替） | 正面リップを **10 mm** に抑えて塞がない |
| 背面 | **送風機プラグ差込口 / 電源ケーブル差込口**（下寄り・片側） | 背面は中央を全開。さらに落とし込みでプラグ位置を角パイプより下へ |
| 背面 | **電池カバー + ツマミ**（回して外す） | 背面をレール外面から 12 mm 離す |

> 差込口の**正確な XY 位置は説明書に寸法記載がない**ため、
> 「背面をほぼ全面開放する」設計にして位置に依存しないようにしています。

### ベッドフレーム

| 項目 | 値 |
|---|---|

## 2. 設計の要点

```
        ← ベッド側          外側 →
              ┌───────────┐            ← M4 クランプねじ ×2
         ●━━━━│  ∩ サドル  │              (ベッド側の脚から締める)
              └─────┬─────┘            角パイプ 43×43 に上からかぶせる
     角パイプ ══════╪══════
                   │  ↕ 12mm スタンドオフ
              ┌────┴──────────┐
              │ サイドプレート  │        ← 背面は中央全開
              │   ┌────────┐   │           (差込口 / 電池カバー逃がし)
              │   │ 制御    │   │
              │   │ タイマー│   │        ← 上から落とし込み
              │   └────────┘   │
              └─┬────────────┬─┘
                └── 床 ───────┘        ← 正面リップ 10mm(ボタンを塞がない)
```

**① 落とし込み量 `DROP = 100 mm` の根拠**

背面の差込口はケーブル／プラグを挿すのに 25〜30 mm の奥行きが必要です。
本体底面を角パイプ上面から 100 mm 下げると、差込口が**角パイプ下端（−43 mm）より下**に来るため、
プラグの後ろは空間になり角パイプに当たりません。
（`DROP` を 98 mm より小さくすると干渉するおそれがあります）

**② スタンドオフ `12 mm`**

背面の電池カバーのツマミが角パイプに当たらないよう、本体背面をレール外面から 12 mm 離しています。

**③ サイドプレート方式**

左右 2 枚の板（厚さ 4 mm）を **Y-Z 平面**に置き、サドルからポケット床まで一枚で繋いでいます。
片持ち曲げに対して最も断面効率のよい向きで、**背面中央には一切構造物を置かずに済む**のが利点です。

概算：本体 500 g ×レール中心からの重心距離 ≒ 68 mm → 曲げ応力は **1 MPa 未満**（PLA の降伏応力の 1/50 以下）。

**④ ケーブル逃がしは左右対称**

背面リップの切り欠きを左右対称にしてあるので、**取り付ける向き（左右）を選びません**。

## 4. 3D プリント

**サポート不要**です。STL / 3MF は既に造形向きで Z=0 に配置してあります。

| 項目 | 推奨 |
|---|---|
| 造形向き | **そのまま**（サドルが上、ポケットの床が造形テーブル面） |
| 材料 | **PETG / ABS / ASA 推奨**。PLA でも可だが、夏場の室温＋常時荷重でのクリープを避けたいなら PETG |
| 積層ピッチ | 0.2 mm |
| ウォール | **4 本以上**（肉厚 4 mm に対して実質ソリッドになる） |
| 充填 | 20 % 以上（グリッド / ジャイロイド） |
| サポート | **不要** |
| ブリッジ | サドル天板の裏側が **43.6 mm のブリッジ**になります。ブリッジが苦手なプリンタはこの部分だけサポートを追加してください |

ねじボスは 45° の円錐にしてあるので、水平方向に出ていてもサポートなしで造形できます。

## 5. 組み立て・取り付け

**用意するもの**：M4 × 25 なべ小ねじ × 2 本（下穴 Ø3.4 のセルフタッピング）

1. ベッドフレームの角パイプに、ホルダーを**上からかぶせる**
2. ベッド側の脚にある 2 つのボスから **M4 ねじをねじ込み**、先端を角パイプに当ててガタを止める
   （締めすぎるとボスが割れます。手応えが出たら止める）
3. 制御タイマーを**上から落とし込む**（ディスプレイと操作ボタンが外側を向く向き）
4. 背面の開口部から**送風機プラグと電源ケーブルを接続**し、背面リップの切り欠きにケーブルを通して下へ逃がす

> **電池交換（年1回）のときは本体を一度持ち上げて外してください。**
> ホルダーに載せたままでは電池カバーのツマミを回すスペースがありません。

## 6. 寸法を変えたいとき

`sac5a_controller_mount.scad` の冒頭パラメータを書き換えて再ビルドします。
よく触るものだけ抜粋：

| パラメータ | 既定値 | 説明 |
|---|---|---|
| `RAIL_W` / `RAIL_H` | 43 | 角パイプの実測断面 |
| `RAIL_CLR` | 0.6 | はめあい。**きつい → 0.8 / ゆるい → 0.4** |
| `DEV_CLR` | 1.5 | 本体まわりの片側クリアランス |
| `LEG_DROP` | 38 | サドルの掛かり深さ |
| `STANDOFF` | 12 | 本体背面と角パイプの隙間 |
| `DROP` | 100 | 落とし込み量（**98 未満にしない**） |
| `SIDE_H_BACK` / `SIDE_H_FRONT` | 72 / 28 | 側板の高さ（背面側 / 正面側） |
| `FRONT_LIP_H` | 10 | 正面リップ。**上げすぎると操作ボタンを塞ぐ** |
| `CLAMP_SCREWS` | true | false にするとねじなしの摩擦保持だけになる |

### ビルド

```sh
./build.sh          # STL / 3MF / プレビュー画像を再生成
```

または個別に：

```sh
openscad --export-format binstl -o stl/sac5a_controller_mount.stl sac5a_controller_mount.scad
openscad -o stl/sac5a_controller_mount.3mf                        sac5a_controller_mount.scad
```

`preview.scad` を OpenSCAD で開くと、制御タイマーと角パイプの想定位置を
半透明で重ねて確認できます。

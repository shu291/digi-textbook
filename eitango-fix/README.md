# 英単語アプリ（eitango）のデータ修復

`shu291/eitango` の単語帳データを、アプリのエクスポート（2026-09-22 時点）を土台に修復したもの。
学習記録（正誤・習熟度・復習日）はすべてそのまま引き継いでいる。

## ファイル

| ファイル | 中身 |
|---|---|
| `eitango-スマホ用.json` | **これ1本でよい。**修復＋全 12 冊の例文を入れた棚（4.00 MB） |
| `eitango-スマホ用-記録なし.json` | 同じ中身で学習記録だけ白紙に戻したもの（3.76 MB） |
| `eitango-repaired.json` | 修復だけ（例文なし）の棚 |
| `修復した内容.tsv` | 何をどう直したかの全件リスト（種類 / デッキ / 前 / 後） |
| `exampleMap-claude.json` | 全 7,759 語の例文を作り直したもの（下記） |
| `例文の新旧対照.tsv` | 旧例文と新例文を並べた対照表 |

## 直したもの（399 件）

### 見出し語の復元（374 件）

熟語の見出し語が、取り込み時にカッコや `～` の空白で英語と訳に切り裂かれていた。

```
前  en="be married (to"   ja="～) （～と）結婚している"
後  en="be married (to ～)" ja="（～と）結婚している"

前  en="as"               ja="～ as ever 相変わらず～"
後  en="as ～ as ever"     ja="相変わらず～"
```

`as` だけの見出し語が 5 枚あり、`as ~ as any` `as ~ as ever` `as ~ as possible` などが
すべて同じ「as」というカードに潰れていた。問題として成立していなかった。

被害は熟語帳に集中している（大学受験英熟語・英熟語ターゲット1000）。

### 訳の誤り（7 件）

変換ミスがそのまま訳に入っていたもの。

12 件が「大学入試英単語網羅版」に集中している（一部は「鉄壁」とも重複）。
`railway` の「鉄壁道」、`underground` の「地下（鉄壁）」のように単語帳名まで
訳に混入しているので、この 2 冊は同じ壊れた元データから取り込まれたとみられる。

同じ単語でも別のデッキでは訳が正しいことがあるため、**単語と「いまの訳」が
完全一致したものだけ**を置き換えている（`call off` は 1400 だけが誤りで、
他の 3 冊は正しい）。

### 見出し語の誤り（2 件）

`businesss` → `business` ／ `tale on` → `take on`

### 重複の統合（3 件）

同じ見出し語が二重に登録されていたものを 1 枚にまとめ、学習記録は合算した。

## 触っていないもの

用法の注記は見出し語の一部ではないので、分割していない。

```
deal       ja="〔deal withで〕を処理する；…"    ← そのまま
atmosphere ja="〔the ～〕大気；雰囲気"           ← そのまま
```

## 使い方

アプリの設定から `eitango-repaired.json` を読み込む。棚ごと差し替わるが、
元のエクスポートを土台にしているので学習記録は失われない。
念のため、読み込む前に現在の状態を「保存」して控えを取っておくこと。

## 例文の作り直し

`exampleMap.json`（単語 → 例文の対応表）を全 7,759 語ぶん作り直した。
元の例文はローカル LLM（gemma3:12b）で作られており、次の問題があった。

- **単語帳の訳と違う意味で使われている** — `board`（板，掲示板）の例文が
  `board of directors`（取締役会）、`link`（結びつける・動詞）の例文が
  `Clicking this link`（名詞）など
- **日本語訳が崩れている／誤訳** — `painful` の "childhood home" を「念願の家」、
  `favor` の訳が一文で二重になっている、など
- **文の型が単調** — 書き出しが `The company…` で 211 回
- カーリー引用符が 630 語（8.1%）に混入

作り直したものは次の条件で作っている。

1. 単語帳の訳の意味でだけ使う（訳が複数あれば第 1 義）
2. 品詞を訳に合わせる
3. 日本語訳は英文と 1 対 1。訳語がそのまま訳文に出る形にする
4. 8〜16 語。正答率が低い語は 8〜12 語で場面が目に浮かぶ文にする
5. 熟語の `A` `B` `one's` `~` `…` は実際の語に置き換える
6. 書き出しを散らす
7. 引用符は ASCII のみ

英文の平均語数は 12.9 → 10.4 語になった。

### 例

```
give off（〜を発する）  0 正解 / 22 誤答

旧  The campfire gave off warmth and a comforting smell of woodsmoke.
    キャンプファイヤーは暖かさと心地よい木の煙の匂いを放っていました。
新  The old engine gave off a strange burning smell.
    その古いエンジンは奇妙な焦げるにおいを発した。
```

旧は訳が「放つ」でカードの訳「発する」と食い違っていた。

### 取り込み方

`shu291/eitango` のリポジトリで次を実行する。Ollama は動かさないので Mac に何も要らない。

```bash
npm run build:examples -- --merge <このファイルのパス>/exampleMap-claude.json
```

`build-examples.mjs` の検査（語数・見出し語の出現・日本語の混入）を通ったものだけが
取り込まれる。落ちた語は元の例文のまま残る。

### 検査結果

7,759 語すべてを生成し、欠けはゼロ。こちらの機械検査では 59 語（0.8%）が
引っかかったが、内訳は活用形の判定漏れ（overcome→overcame、die→dying）と
訳語照合の粗さで、大半は誤検出。データ側の誤訳をそのまま検出したものも含む。

## スマホだけで使う（`eitango-スマホ用.json`）

例文はアプリ本体に同梱されているので、ふつうは差し替えるのに再ビルドと配信が要る。
ただし単語が `ex: { en, ja }` を持っていればそちらが優先される
（[`src/lib/examples.js`](../../shu291/eitango/src/lib/examples.js) の `exampleFor`）。
これを使って、**取り込み 1 回だけで修復と例文の両方が入る**ファイルにした。
Mac もデプロイも要らない。

### 容量

保存先は **IndexedDB**（[`src/lib/storage.web.js`](../../shu291/eitango/src/lib/storage.web.js)）。
iPhone でも数百 MB 使える。よく言われる 5MB の上限は localStorage のもので、
このアプリでは IndexedDB が使えない場合のフォールバックにしか当たらない。

そのうえで、**既定値と同じフィールドは書かない**ようにしている。取り込み時に
`normalizeWord` が `progress: w.progress || 0` のように復元するので情報は減らず、
読み込みも速い。

| | 容量 |
|---|---|
| 元のデータ | 4.42 MB |
| 既定値を省く | 2.05 MB |
| ＋ 全 12 冊ぶんの例文 | **4.00 MB** |

削ったぶんが例文の容量を上回るので、**元より小さくなっている**。
22,289 語（ユニーク 7,816 語）に例文が付く。付かないのは 3 語だけ。

### 引き継がれるもの

正誤の回数・習熟度・連続正解・復習日・次に出す日・EF 値・学習時間、すべてそのまま。
`srv`（復習の予定の版）も引き継ぐので、取り込み時に予定がリセットされることもない。

```json
{"en":"give off","ja":"〜を発する","incorrect":22,"due":"2026-09-22","ef":1.3,
 "ex":{"en":"The old engine gave off a strange burning smell.",
       "ja":"その古いエンジンは奇妙な焦げるにおいを発した。"}}
```

### 手順

1. スマホに `eitango-スマホ用.json` をダウンロードする
2. **先にアプリの「保存」で今の状態の控えを取る**（読み込むと棚ごと入れ替わる）
3. アプリの「読み込み」でこのファイルを選ぶ

うまくいかなかったら、控えを読み込めば元に戻る。

## 学習記録なし版（`eitango-スマホ用-記録なし.json`）

単語・訳・例文・デッキ構成は `eitango-スマホ用.json` と同じで、学習記録だけを消したもの。

消したもの:

- 単語ごと — 正誤の回数、習熟度、連続正解、最後に学習した日、復習した日の一覧、
  次に出す日、EF 値
- 棚ごと — 連続日数、最後に学習した日、学習時間の記録

残したもの: 単語、訳、例文、デッキの構成と並び、単語の id。

```json
{"id":586,"en":"give off","ja":"〜を発する",
 "ex":{"en":"The old engine gave off a strange burning smell.",
       "ja":"その古いエンジンは奇妙な焦げるにおいを発した。"}}
```

取り込み時に `normalizeWord` が初期値（progress 0 / ef 2.5 / due なし）で埋めるので、
どの単語も「まだ一度も解いていない」状態から始まる。

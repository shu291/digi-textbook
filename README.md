# じぶん教科書

スキャンした教科書のPDFを取り込んで、**読む・書き込む・赤シートで覚える・検索する**ためのデジタル教科書アプリ。
ブラウザだけで動く PWA（ホーム画面に追加すればアプリみたいに使える）。

**公開URL: https://shu291.github.io/digi-textbook/**
（iPhone/iPad の Safari で開く → 共有 → ホーム画面に追加）

- 場所: `/Users/so/digi-textbook/`
- データは**端末の中（IndexedDB）だけ**に保存。教科書の中身は外部に一切送られない
  （自分でスキャンした教科書を自分で使う＝私的利用の範囲）
- 費用: 0円（pdf.js / Tesseract.js とも無料。CDN から読み込み）

## 機能

| 機能 | 内容 |
|---|---|
| 本棚 | 表紙サムネ・教科の色分け・「つづき p.N」表示。名前/教科の変更・削除 |
| 取り込み | PDF → 各ページを画像化（長辺2000px JPEG）して保存。進捗バー・中止つき |
| リーダー | スワイプ/端タップ/矢印キーでめくり・ピンチズーム・ダブルタップ拡大・ページスライダー |
| 書き込み | ペン3色×3太さ・マーカー3色・消しゴム（線単位）・もどす/やり直す |
| 暗記マーカー | 緑で塗る → **赤シートON で赤い帯になって隠れる → タップでめくれる**。ぜんぶかくす/見る |
| 向きの回転 | 横倒し・逆さまスキャンを一括回転（90°/180°）。「ぜんぶ」か「一部だけ（pX〜pY）」を選べる。書き込み・サムネ・表紙も一緒に回る。途中で止まっても続きから再開 |
| ページ追加 | 分割スキャンした続きのPDFを、既存の本の後ろにつなげられる。確認画面のプレビューで向きを合わせてから追加できる。書き込み・しおり・目次はそのまま。失敗時は自動で巻き戻し |
| 並べ替え | ページ一覧の「並べ替え」モードで、ページの入れ替え・移動ができる（スキャン順の狂い直し）。書き込み・しおり・目次・表紙も追従 |
| しおり・目次 | しおりは右上ボタン。目次は「このページに章を追加」でジャンプできる |
| ページ一覧 | サムネのグリッド。現在ページ・しおり・章のマークつき |
| 検索 | 本の中/全部の本から。ひらがな⇔カタカナ・全角半角ゆらぎ対応。スニペット表示 |
| OCR | テキストのないスキャンPDFは Tesseract.js（日本語+英語）で文字認識。裏で実行・中止可 |
| バックアップ | 書き込み・目次・しおり・文字データを JSON で書き出し/読み込み |
| Apple Pencil | ペンを検出すると「指=スクロール/ペン=描く」に自動切替（⋯メニューで変更可） |

## 使い方

### Mac でためす

```bash
python3 -m http.server 8797 --directory /Users/so/digi-textbook
```

→ http://localhost:8797 を開く。`sample-textbook.pdf`（テスト用サンプル・消してOK）で試せる。
Claude Code からは launch.json の `digi-textbook` でも起動できる。

### iPhone / iPad で使う

GitHub Pages で公開するのがいちばん簡単（ミスノートと同じ方式）:

1. GitHub に public リポジトリを作って、このフォルダを push
2. Settings → Pages → main ブランチ root を公開
3. iPhone/iPad の Safari で開く → 共有 → **ホーム画面に追加**

公開されるのは**アプリ本体だけ**（約80KB）。教科書PDFや書き込みは各端末の中にしか保存されない。

## しくみ（技術メモ)

- 構成: `index.html` + `style.css` + `js/`（main / reader / draw / importer / ocr / db / util）+ `sw.js` + `manifest.webmanifest`
- PDF表示: [pdf.js 4.6.82](https://cdn.jsdelivr.net/npm/pdfjs-dist@4.6.82/)（CDN・バージョン固定）。取り込み時に一度だけ使い、以後は保存済み画像を表示するので速い
- OCR: [Tesseract.js 5.1.1](https://cdn.jsdelivr.net/npm/tesseract.js@5.1.1/) + tessdata_fast (jpn+eng)。実行時のみ読み込み
- 保存: IndexedDB `digi-textbook`
  - `books`（メタ・目次・しおり・表紙）/ `pages`（サムネ・テキスト）/ `images`（ページ画像）/ `strokes`（書き込み）/ `prefs`
- 書き込みは 0..1 の正規化座標で保存 → 画像解像度やズームに影響されない
- 検索: 保存時 NFKC 正規化＋CJK間の空白除去、検索時 小文字化＋カタカナ→ひらがな（1:1変換なのでスニペット位置がズレない）
- Service Worker: 本番(https)のみ有効。localhost では `?sw` を付けたときだけ登録（開発中のキャッシュ事故防止）
- 縦書きの本は OCR 精度が落ちる（Tesseract の限界）。横書き教科書向き

## 検証ずみの動作（2026-08-09・Playwright）

- PDF取り込み（6ページ・テキスト層自動抽出・表紙生成）
- ページめくり（キー・スライダー・検索ジャンプ・つづきから再開）
- ペン描画（スムージング）・消しゴム・undo/redo・リロード後の永続化
- 暗記マーカー → 赤シートON「かくし中 2/2」→ タップで1つめくれて「1/2」
- しおり・目次追加・ページ一覧（現在強調/リボン/章マーク）
- 本内検索「光合成」5ページヒット、OCR後の全体検索「ミトコンドリア」「みとこんどりあ」両方ヒット
- OCR 6ページ完走（リーダーを閉じても継続・完了トースト）
- ピンチズーム（scale 1.96・パン追従）
- バックアップJSON書き出し（strokes 3 / toc 1 / bookmarks 1 / texts 6）
- iPhoneサイズ(390×844)とデスクトップ両レイアウト・コンソールエラー0
- 向きの回転: 横倒しPDF(3ページ)を左90°で復元、書き込みありの本を180°→180°で完全に元通り（マーカー/ペンが文字に追従）。本棚メニューとリーダー⋯メニュー両方の動線OK

回転のしくみ: 表示時に回すのではなく、保存済みページ画像・サムネ・表紙を回して保存し直す（書き込みは正規化座標を式変換、90°系は太さも補正）。進行状況を `book.rotatePending` に記録し、途中で閉じても「つづきから再開」できる（ページ混在を防ぐ）。

- ページ追加: 既存6ページの本に6ページのPDFを追加→全12ページ、既存の書き込み・しおり・目次が無傷、追加分のテキスト層も検索にヒット（2026-08-09 Playwright確認）
- 向き混在の治療: 正しい向きの本(12p)に横倒しPDFを追加→p13〜15だけ「一部だけ」回転で復元、p1〜12と書き込みは完全無傷
- 向き合わせ追加: 追加確認画面のプレビューを左90°回して追加→追加分が最初から本と同じ向きに
- 並べ替え: p1⇄p5入れ替え・p4をp2の前へ移動→書き込み(p3→p4)・しおり(4→2)・目次・表紙が全部追従、逆操作で完全復元。連続操作OK
- 容量実測(147ページの実本): ページ画像54.3MB に対し文字データ343KB(約1/160)。OCRエンジンは初回のみ約10MBをキャッシュ
- 書き込み保存の堅牢性: 描く→リロード→180°回転→180°戻しで、座標が小数2桁まで完全に元通りになることを確認
- 更新の配信: アプリのファイルを変えたら `sw.js` の `VER` を上げること。上げないと公開版（https）で古いキャッシュが配られ続ける

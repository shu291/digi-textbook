# sac5a_arm_bot — ESP32 ボタン押しロボット

SAC-5A の［アラーム］ボタンを、毎晩決まった時刻に SG90 サーボで物理的に 1 回押すロボットです。
スマホのブラウザから `http://sac5a.local/` を開いて、曜日ごとの押し時刻・スキップ・テスト押しを操作できます。

本体（SAC-5A）には一切手を加えません。サーボを外側から貼り付けるだけです。

## 部品表

| 部品 | 目安価格 | 備考 |
|---|---|---|
| ESP32 開発ボード（ESP32-DevKitC 系） | 約1,000〜1,600円 | 秋月電子・Amazon など。USB で書き込めるものなら何でも可 |
| SG90 マイクロサーボ | 約400〜600円 | トルク 1.8kgf・cm。タクトボタンを押すには十分 |
| ジャンパワイヤ（メス-メス or メス-オス） | 約200円 | 3 本使う |
| USB 電源アダプタ + microUSB/USB-C ケーブル | 手持ちでOK | スマホ用充電器で十分（5V 1A あれば余裕） |
| 両面テープ・マスキングテープ・結束バンド | 手持ちでOK | サーボの固定用 |

合計 2,000 円前後。はんだ付けは不要です（ピンヘッダ実装済みボードを買うこと）。

## 配線

SG90 のコネクタにジャンパワイヤを挿して ESP32 につなぐだけです。

```
SG90 サーボ            ESP32 DevKit
─────────────         ─────────────
橙（信号）   ────────  GPIO13
赤（VCC）    ────────  5V（VIN と表記のボードもある）
茶（GND）    ────────  GND
```

> SG90 1 個なら ESP32 ボードの 5V ピンから直接給電で問題ありません。
> 動作中にサーボがカクつく場合は、USB アダプタを 2A 品に変えてください。

## 書き込み手順（Arduino IDE）

1. [Arduino IDE](https://www.arduino.cc/en/software) をインストール
2. 環境設定 → 追加のボードマネージャの URL に
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json` を追加
3. ボードマネージャで **esp32 by Espressif Systems** をインストール
4. ライブラリマネージャで **ESP32Servo**（Kevin Harrington）をインストール
5. `sac5a_arm_bot.ino` を開き、ボードに **ESP32 Dev Module** を選択して書き込み

## 初回セットアップ

1. 書き込み後、ESP32 は Wi-Fi 未設定なので設定用アクセスポイントを立てます
   - スマホの Wi-Fi 設定で **`SAC5A-setup`**（パスワード `sac5a-setup`）に接続
2. ブラウザで `http://192.168.4.1/` を開く
3. 「Wi-Fi 設定」に自宅の SSID とパスワードを入れて保存 → 自動で再起動
4. スマホを自宅 Wi-Fi に戻し、`http://sac5a.local/` を開く
   - 開けない場合はルーターの管理画面などで ESP32 の IP アドレスを調べて `http://<IP>/` でアクセス
5. 時刻は NTP（ntp.nict.jp）から自動取得されます。「状態」欄で現在時刻が合っていることを確認

## サーボの取り付けとキャリブレーション

1. SAC-5A の制御タイマーの［アラーム］ボタンの位置を確認する
2. サーボホーン（腕）がボタンの真上に来るように、サーボを両面テープ + マスキングテープで仮固定
   - **停止A・停止B ボタンとディスプレイを塞がないこと**（起床時に押せなくなる）
3. Web UI の「サーボ調整」で角度を合わせる
   - 待機角度: 腕がボタンに触れないギリギリの位置
   - 押し込み角度: ボタンがしっかり「カチッ」と入る位置（押しすぎて本体を痛めない範囲で）
   - 「保存して試し押し」で実際に Alarm ON になるか確認（アラーム LED が点灯すればOK。もう一度押すと解除されるので、テスト後は LED の状態に注意）
4. 位置が決まったら本固定（強力両面テープ、または結束バンド + 土台）

```
        ┌──────────────┐
        │  SAC-5A 制御タイマー │
        │  ┌────────┐  │
        │  │ ディスプレイ │  │
        │  └────────┘  │
        │   [ア] [起] [メ] …   │ ← ボタン列
        └───▲──────────┘
            │ サーボホーンが真上から押す
        ┌───┴───┐
        │ SG90  │←両面テープで本体横 or 台に固定
        └───────┘
```

## 毎日の運用

- 「自動押しスケジュール」で曜日ごとに押す時刻を設定（例: 平日 21:30）
  - これは**予約ボタンを押す時刻**（寝る前）です。起きる時刻は SAC-5A 本体側の設定が使われます
- 起きたら今まで通り 停止A + 停止B を同時押し。夜になればまた自動で予約されます
- 明日は起きなくていい日 → 「次の1回だけスキップ」を押す
- 起きる時刻を変えたい日 → SAC-5A 本体で起床時刻を変更して［決定］（この操作自体で予約も入る）。その夜の自動押しは「スキップ」しておく（予約済みの状態で押すと解除されてしまうため)

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| `sac5a.local` が開けない | Android の一部は mDNS 非対応。ルーターで IP を調べて直接アクセス。IP を固定（DHCP 予約）しておくと楽 |
| 押しても Alarm ON にならない | 押し込み角度を深く / 保持時間を長く。サーボの固定がずれていないか確認 |
| 逆に予約が解除されている | 二重押しの疑い。手でアラームボタンを押す運用をやめる。ログで押した時刻を確認 |
| 時刻未同期のまま | Wi-Fi がインターネットに出られているか確認（自動押しは時刻同期するまで安全側で停止します） |
| サーボがジジジと鳴り続ける | このファームは押した後に脱力（detach）するので通常鳴りません。鳴るなら待機角度で腕がどこかに接触しています |

## 仕様メモ

- 押し忘れ防止のため、押した記録（分単位）は NVS に保存され、再起動しても同じ分に二度押ししません
- 停電・再起動後は Wi-Fi 再接続 → NTP 再同期後にスケジュール監視を再開します
- 時刻が未同期の間は絶対に押しません（変な時刻に押して予約解除する事故の防止）

# 部長と峠 操作アシスト

<https://oichikonnyaku.com/touge/> の操作を、細かく・やりやすくする Chrome 拡張機能です。
自動運転や記録の書き換えはしません。走るのは自分で、ランキングにもそのまま登録できます。

## できること

| 機能 | 内容 |
|---|---|
| ゲームパッド | 左スティック＝ハンドル（遊び・カーブを調整可）、LT/RT またはスティック下＝ブレーキ（段階的）、十字キー＝キーボードと同じ段階操作 |
| キーボードの段階操作 | ← → ↓（または A D S）を押し続けるほど切れていく。Shift 中は最大切れ角を抑える（標準は「即・全開」） |
| マウス操作 | マウスの左右の位置＝ハンドル、左クリック押下中＝ブレーキ（既定ではオフ） |
| 画面表示 | 左下に速度・ハンドル量・ブレーキ量・入力元を表示。指定速度を超えたらビープ音（既定ではオフ） |
| 感度 | ハンドル・ブレーキの感度を全体でまとめて調整（0.3〜2倍） |
| 練習スロー | 自分で走るときのスロー・一時停止（既定ではオフ。ポップアップで許可）。**使うと、ページを開き直すまでランキング送信と自己ベストの保存が止まります** |
| 走りを見る | 「全国トップの走りを見る」の最中だけ、Space＝一時停止、`,`＝遅く、`.`＝速く（右下のボタンでも可） |

設定は、ツールバーの拡張機能アイコンから変えられます。

## 仕組み

ゲームは「画面に指を置いて横にずらした量＝ハンドルの切れ角、下にずらした量＝ブレーキ」で操作します。
この拡張機能は、キー・ゲームパッド・マウスの入力をその「指の動き」に変換して、ゲームの `#touch` 領域に渡します。
ゲーム内部の値は読み書きしません。

「走りを見る」の再生速度は `requestAnimationFrame` の時間を伸ばして変えています。
自分で走っているときは、練習スローを許可しない限り何もしません。許可してスローを使った場合は、スローで出したタイムが記録にならないよう、ランキングへの送信と自己ベストの保存をそのページの間だけ止めます。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダ（`touge-assist`）を選ぶ
4. `https://oichikonnyaku.com/touge/` を開き直す

## 注意

- ゲームパッドは、接続したあとにどれかのボタンを押すと認識されます（ブラウザの仕様）。
- ゲーム側のアップデートで画面の作りが変わると、動かなくなることがあります。

# ころころ電池ソーター(単3・単4 自動仕分けケース)

電池を上の投入口から**転がして入れるだけ**で、単3と単4をサイズの違いで自動的に
仕分けし、それぞれのビンに**きれいに整列**させて溜めるケースの3Dモデル。
**Bambu Lab A1 mini(180×180×180mm)でそのまま印刷できるサイズ**(178×59.5×122mm)。

印刷するファイルは **`battery_sorter.stl`**(これをスライサーに入れるだけ)。

![プレビュー](preview_iso1.svg)

## 仕分けの仕組み(サイズ差の利用)

| | 直径 | 長さ |
|---|---|---|
| 単3 (AA) | 14.5 mm | 50.5 mm |
| 単4 (AAA) | 10.5 mm | 44.5 mm |

「長さの差 6mm」を使う。上段の坂(勾配10°)の床に **幅46mmのスロット(長穴)** が
開いている。

1. 投入口から入れた電池は横向きに寝て坂を転がる(開口は37mmで単4の長さより
   狭いので、間違った向きでは物理的に入らない)
2. **単4(長さ44.5mm)** … 44.5 < 46 なのでスロットを橋渡しできず、**必ず落ちる**。
   下段の坂(勾配7.7°)で右端へ運ばれ、単4ビンへ
3. **単3(長さ50.5mm)** … スロットの両脇に残した幅3.25mmの棚(レッジ)に両端が
   常に乗って通過。ビンの側壁が斜めへの向き変わりも防ぐので、**幾何学的に
   絶対に落ちない**(転がる速さや勢いに関係なく確実)。そのまま坂を転がりきり、
   左端から単3ビンへ落ちる

## 収納と取り出し

- 各ビンは内幅を「電池の長さ+約2mm」にしてあるので、電池は自動的に**向きが
  そろい**、床の傾き(5°)で**中央の仕切りに向かって転がって積み重なる**
- 収納数の目安: **単3 約14本、単4 約22本**
- 前面の**大きな取り出し窓(46×40mm)が仕切りの両脇に2つ**。床の傾きで
  いちばん下の電池が常に窓の前に来るので、つまんで取るだけ。減ると
  次の電池が自動的に転がってくる

## ファイル

| ファイル | 内容 |
|---|---|
| `battery_sorter.stl` | **印刷用の3Dモデル本体**(バイナリSTL、単位mm) |
| `generate.py` | STLを生成するスクリプト(**Python標準ライブラリのみ**、依存なし)。寸法の変更もここで |
| `preview_iso1.svg` | プレビュー画像(generate.py が生成) |

```bash
python3 generate.py   # 寸法を変えたら再実行して STL を再生成
```

## 主要寸法

- 外形: **178 × 59.5 × 122 mm**(A1 mini のビルドボリューム180mm角に収まる)
- 仕分けスロット: 幅46 × 開口50mm、レッジ幅3.25mm
- 単3ビン内幅 52.5mm / 単4ビン内幅 46mm(全高で整列を維持)
- 壁厚 3〜3.5mm、坂の板厚 4mm、一体型(組み立て不要)

## 3Dプリントするときのメモ

- 底面をベッドにして立てたまま印刷し、坂と天板の下にサポートを付けるのが素直
- プリンタの誤差によっては `generate.py` の `slot_w`(46mm)を±0.5mm調整
  (単4が引っかかる→広げる / 単3の端の乗りが浅い→狭める)
- 坂の上面のシームやサポート跡は軽くやすりがけすると電池がよく転がる
- 実物で試す前に、単3がスロットを渡ること・単4が落ちることを1本ずつ確認

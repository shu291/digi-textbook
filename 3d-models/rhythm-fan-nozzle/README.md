# リズム ハンディファン用 風集めノズル（集風器）

ハンディファンの頭にかぶせて、広がってしまう風を一箇所に絞って飛ばすためのアタッチメント。
3Dプリンタ用の STL と、寸法を変えて作り直せる生成スクリプトが入っている。

![断面図](cross-section.svg)

## ファイル

| ファイル | 中身 |
| --- | --- |
| `rhythm-fan-nozzle.stl` | 標準版。まずはこれを印刷する |
| `rhythm-fan-nozzle-vanes.stl` | 出口に十字の整流フィンを追加した版。風の渦が気になるとき |
| `fan_nozzle.py` | STL を作り直すスクリプト（Python 3 標準ライブラリのみ） |
| `cross-section.svg` | 断面の形（標準版） |

## ⚠️ 最初に確認すること

**ファン頭部の外径は 76 mm と仮定している。** リズムのハンディファンは機種によって
頭のサイズが違うので、**手元の実機をノギスや定規で測って**、値が違ったら下の
「寸法を変える」の手順で作り直してほしい。測るのは、ノズルをかぶせたい
**円い頭の部分のいちばん外側の直径**。

## 標準版の寸法

| 項目 | 値 |
| --- | --- |
| 全高 | 80.0 mm |
| 最大外径 | 81.2 mm |
| 差しこみ口の内径 | 77.2 mm（ファン外径 76 mm ＋ 片側 0.6 mm のすきま） |
| えり（差しこみ部）の深さ | 20 mm |
| 吹き出し口の内径 | 26 mm |
| 肉厚 | 2.0 mm |
| 断面の絞り比 | 約 8.5 倍 |

絞り比は「入口の面積 ÷ 出口の面積」。理屈のうえでは出口の風速がこの倍率だけ上がる
（実際はファンの静圧が足りないぶん風量が落ちるので、そこまでは上がらない）。
出口を小さくするほど遠くまで届くが、絞りすぎるとファンが風を押し出せなくなって
かえって弱くなる。26 mm はその中間をねらった値。

形は途中でカクッと折れないよう、なめらかな曲線（smoothstep）で絞っている。
急に絞ると内壁で流れがはがれて、出口の風が細くならずに乱れるため。

## 印刷の設定

- **置きかた**: 差しこみ口（太いほう）を下にして、吹き出し口を上に向ける
- **サポート**: 不要。壁の傾きは最大でも垂直から約 40° なので自立する
- **ブリム**: 推奨。底の接地が幅 2 mm のリングだけなので、はがれ防止に
- **積層ピッチ**: 0.2 mm
- **壁**: 3 周（肉厚 2 mm に対して）／**充填**: 15 % 程度
- **材料**: PLA でも作れるが、夏の車内や直射日光で変形しやすい。**PETG 推奨**

## はめ具合の調整

印刷してみてキツい／ゆるいときは `--clearance`（片側のすきま）で直す。

- キツくて入らない → 値を大きく（例 `--clearance 0.9`）
- ゆるくて落ちる → 値を小さく（例 `--clearance 0.3`）

ゆるいまま使いたい場合は、えりの内側に養生テープを一周貼るだけでも止まる。

## 寸法を変える

```bash
# ファン外径が 82 mm、もっと絞りたいとき
python3 fan_nozzle.py --fan-od 82 --outlet-d 22 -o mynozzle.stl

# 整流フィン付きで作る
python3 fan_nozzle.py --fan-od 82 --vanes 4 -o mynozzle-vanes.stl

# 全オプション
python3 fan_nozzle.py --help
```

主なオプション:

| オプション | 既定値 | 意味 |
| --- | --- | --- |
| `--fan-od` | 76 | ファン頭部の外径 mm |
| `--clearance` | 0.6 | はめあいのすきま（片側）mm |
| `--outlet-d` | 26 | 吹き出し口の内径 mm |
| `--collar-h` | 20 | えりの深さ mm |
| `--taper-h` | 46 | 絞り部分の高さ mm |
| `--throat-h` | 14 | 出口ストレートの高さ mm |
| `--wall` | 2.0 | 肉厚 mm |
| `--vanes` | 0 | 整流フィンの枚数（0 か 4） |
| `--segments` | 192 | 円周の分割数。増やすと滑らかで重くなる |

実行するとその場で寸法と絞り比が表示されるので、印刷前の確認に使える。

## 安全について

- 羽根に触れる位置までノズルが入らないよう、えりの奥は絞りで塞がる構造にしてある。
  それでも **ファンを止めてから** 抜き差しすること
- 出口を手や布で完全にふさぐとモーターに負荷がかかるので避ける

## 作りかた（スクリプトの中身）

内壁の輪郭を `(高さ z, 半径 r)` の折れ線で定義し、それを z 軸まわりに 360° 回転させて
内壁・外壁をつくり、上下をリングでフタして閉じた立体にしている。
出力はバイナリ STL。生成物は全三角形の有向辺が 1 回ずつ現れる
（＝穴なし・法線の向きがそろった）閉じたメッシュになっていることを確認済み。
